# Loja-Alura-Store

Análise de Desempenho das Lojas - Alura Store 🏬📊

Este projeto tem como objetivo analisar os dados de desempenho de quatro lojas pertencentes ao e-commerce Alura Store, com o intuito de ajudar o Sr. João a decidir qual loja vender para obter capital e investir em um novo negócio.


---

🎯 Objetivo

Avaliar os seguintes critérios de cada loja:

💰 Faturamento total

🛍 Categorias de produtos mais vendidas

⭐ Média de avaliação dos clientes

📦 Produtos mais e menos vendidos

🚚 Custo médio de frete


Com base nessas análises, indicar qual loja apresenta o pior desempenho e é a mais recomendada para venda.


---

🛠 Ferramentas utilizadas

🐍 Python

📋 Pandas — manipulação de dados

📊 Matplotlib e Seaborn — visualização de dados

☁ Google Colab — ambiente de desenvolvimento



---

📌 Etapas da Análise

1. 📥 Importação dos dados das quatro lojas


2. 🧹 Limpeza e padronização das colunas


3. 📈 Cálculo das seguintes métricas por loja:

Faturamento total

Frete médio

Avaliação média

Categorias mais vendidas

Produtos mais e menos vendidos



4. 📉 Criação de gráficos:

Gráfico de barras para faturamento

Gráfico de barras para avaliação média

Gráfico de pizza com categorias mais vendidas



5. 🏅 Geração de um ranking das lojas


6. ✅ Recomendação final: qual loja vender




---

🏁 Resultado da Análise

Com base nos dados analisados, foi recomendado que o Sr. João venda a Loja 4 🏷, pois ela apresentou:

📉 O menor faturamento

⭐ A pior média de avaliação dos clientes

🚚 Um dos maiores custos médios de frete

📦 Baixa performance em vendas de produtos e categorias



---

▶ Como executar o projeto

1. Acesse o notebook no Google Colab


2. Execute todas as células sequencialmente


3. Analise os gráficos e a recomendação final
